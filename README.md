# Infrastructure Delay Prediction Model

## Mission
Modernizing infrastructure project delivery in South Africa.

## Project Overview
This project uses machine learning to predict project delays (in days) for construction project managers and city planners. By predicting delays early, stakeholders can plan resources better and reduce cost overruns.

## Repository Structure
*   `linear_regression/`: Contains the Jupyter notebook (`multivariate.ipynb`), the cleaned dataset, and the saved `best_model.pkl`.
*   `API/`: Contains the FastAPI backend code (`prediction.py`, `model_script.py`), requirements, and the API dataset.
*   `flutter_App/`: Contains the Flutter mobile application code.

## Dataset Source
The data was sourced from the South African National Treasury's Infrastructure Reporting Model (IRM), focusing on real-world provincial infrastructure projects.
